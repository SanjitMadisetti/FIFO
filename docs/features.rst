In this model the pointers *write_ptr* and *read_ptr* have been sized to wrap at the stack boundary so the condition of an empty stack cannot be distinguished from the condition of a full stack by compring the points. Instead, the pointers are derived from counters which are one bit wider, by formting ptr_gap as the difference between the counts held in wr_cntr and rd_cntr. The contents of ptr_gap are effectively incremented, decremented or held, depending on the condition of the stack and whether a write operation and/or a read operation is attempted. When the value stored in *ptr_gap* reaches *stk_height* (8), the FIFO is full. If the stack is full, only a read is allowed; if the stack is empty only a write is allowed. The reset signal initialized the counters but not the memory registers of the FIFO.
